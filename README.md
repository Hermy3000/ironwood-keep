# Ironwood Keep

A 3D tower defense in the spirit of classic Warcraft 2-era sieges. Hold the stone keep against ten Ashclan warbands with ballistae, catapults, cannon, and mage spires.

## Play

- Place towers on the stone plots along the road
- Right-drag to look, WASD to pan, wheel to zoom
- Iso / Top / Cinematic / Keep / Camp camera presets on the right
- Archer, Ballista, Catapult, Cannon, Mage Spire
- Upgrade, sell, and retarget (first / last / closest / strongest)

## Controls

| Input | Action |
| --- | --- |
| Left click | Place or select a tower |
| Right drag | Orbit the battlefield |
| Middle drag / WASD | Pan |
| Mouse wheel | Zoom |
| Q / E | Roll tilt |
| Camera chips | Jump to a view |

## Local

```bash
npm install
npm run dev
```

Open the printed local URL. `npm run build` produces a Vercel-ready output via Nitro.

## Stack

React, TanStack Start, Three.js, Zustand, Tailwind v4.
